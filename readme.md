# 🧭 Constitution Watch – Public Demo Pointer

This public repository hosts a static landing page that links to the live **Constitution Watch** demo site.

The live project is part of an ongoing civic initiative to track government actions against constitutional principles using a trait-based evaluation system. This pointer page is intended for portfolio visibility, demonstration, and public reference.

---

## ⚠️ Development Status

🚧 The full source code, including trait matching logic, scoring algorithms, and event infrastructure, is maintained in a **private repository**.

This public page is a **read-only pointer** and does not expose core logic, trait files, or internal scoring architecture.
